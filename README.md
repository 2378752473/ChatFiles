# ChatFiles 0.2.8

**记得 Codex 对话的名字，却想不起那次实验的波形、报告和构建文件放在哪？**

ChatFiles 是一个 Windows 离线工具。搜到对话，就能打开它关联的工作目录，看哪些文件最占空间。几轮仿真留下的波形、反复打包的旧构建，可以按类型和大小筛出来。多个对话共用一个目录时，空间合计会去重。确认具体路径和关联对话后，你可以把选中的文件移入回收站。

这些目录里也可能有源码、原始素材和最终成果。先查看，再决定留什么。整个过程在本机完成。

[下载 Windows x64 便携版](https://github.com/2378752473/ChatFiles/releases/latest)。解压后双击 `ChatFiles.exe`，无需安装 Python。也可以在 Windows 上用 Python 3.12（含 Tcl/Tk）运行源码。

## 使用

1. 软件优先自动识别 CODEX_HOME 或用户目录下的 `.codex/state_*.sqlite` 数据库，读取对话名称及工作目录。
2. 如果识别失败，打开“对话目录设置”，用“选择目录”选择桌面端的用户数据目录，或“选择数据库”指定 state_*.sqlite。点击“如何找到对话目录？”可查看查找步骤，直接复制路径、打开文件夹或使用本机识别的目录。
3. 读取对话后，软件在后台逐步填入工作目录大小，并隐藏内部代理记录。搜索并选择对话。右侧只读扫描该工作目录，按文件大小降序显示。点击“刷新大小”可更新目录大小。列表上方的“对话目录合计（去重）”包含搜索未显示的对话。共享目录只计一次，父目录已计入时不再叠加子目录。无法读取或只读到一部分的目录单独标出。
4. 右侧支持 Ctrl / Shift 多选文件；点击底部红色“移入回收站”按钮，核对完整路径和相关对话，勾选确认后交给 Windows 回收站处理。若 Windows 提示永久删除，请取消。清理失败时，窗口会显示 Windows 返回的原因或说明原因未明。可以复制路径、打开目标或上级目录，在资源管理器核对剩余文件并手动清理。软件保护类提示会说明如何处理。
5. 双击文件可通过系统关联程序打开。双击标为“文件夹”的行，会在资源管理器打开该目录。文件类型、大小与名称可同时筛选。点击左侧“大小”列头切换按大小和按最近更新排列。需要完整清单时点击导出。右侧列表显示最大的 15,000 个文件，导出包括全部扫描文件。

## 归属与兼容范围

- 本版针对带有本地 Codex 对话索引的桌面端。会显示归档对话。程序只读数据库，不更改、删除对话记录。
- 普通 ChatGPT 若没有本地工作目录索引，不能通过安装目录自动知道某条云端对话生成了哪些本地文件。本版会提示无法识别，不猜测归属。
- 目录关联不等于文件创建来源。源码、导入素材、用户手动放入的文件、构建产物等都可能出现在同一目录。
- 多条对话共用同一路径，或工作目录相互嵌套时会标注。它们不是各有一份独立文件，大小不能直接相加。确认清理时会列出所有关联对话。
- 没有可靠映射的其他目录、仅存在云端的附件、已删除文件、虚拟机内部文件不在自动识别范围。
- 大小是文件逻辑大小，硬链接、压缩、稀疏文件及后台变化会影响实际占用和回收量。扫描跳过符号链接和目录联接，读取异常会提示。

## 清理范围

AI 对话关联的工作目录可能包含源码、报告、实验结果和原始素材。请先核对文件用途，再清理确认不再需要的内容。

底部“移入回收站”处理选中文件。“删除整个目录”处理当前对话关联的工作目录及其全部内容，包括子目录和版本库。确认窗口会列出完整路径和关联对话。系统目录、用户主目录、对话索引和本程序所在目录受保护。若 Windows 提示永久删除，请取消。

回收站仍占磁盘空间，需要用户核对后清空回收站才真正腾出容量。程序不提供永久删除按钮。请保留源码、最终成果、唯一研究数据和需要复查的验证证据。
